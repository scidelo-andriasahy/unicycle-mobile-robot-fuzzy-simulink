## Overview
Non-holonomic unicycle mobile robot modeling and closed-loop trajectory tracking using Mamdani Fuzzy Inference Systems (`MobileRobot_3MF.fis`, `RobotStable11.fis`) in **MATLAB/Simulink** (`Robot_Unicycle_Mobile.slx`, `bloc.slx`).
